# Стратег для маркетплейсов

Простой рабочий MVP AI-платформы для продавцов маркетплейсов: загружаете выгрузки Ozon/Wildberries, сервис нормализует отчёты, считает метрики, учитывает юнит-экономику и формирует стратегию роста продаж на месяц.

## Что есть

- Frontend: React + TypeScript + Vite.
- Backend: Express API.
- Без регистрации, оплаты и базы данных.
- Данные хранятся только в памяти запущенного сервера.
- Серверная загрузка CSV, XLSX, XLS и ODS.
- Мультизагрузка: можно отправить сразу несколько отчётов и получить единый анализ по SKU.
- Готовые пресеты под выгрузки Ozon/Wildberries.
- Нормализация типов отчётов:
  - продажи;
  - реклама;
  - остатки;
  - акции/промо.
- Справочник юнит-экономики по SKU:
  - себестоимость;
  - комиссия;
  - эквайринг;
  - логистика;
  - налог.
- Импорт справочника юнит-экономики из XLSX/CSV/ODS.
- Метрики:
  - продажи;
  - заказы;
  - ДДР;
  - маржа;
  - остатки;
  - расходы по юнит-экономике;
  - показы;
  - клики;
  - корзины;
  - конверсии показ→клик, клик→корзина, корзина→заказ.
- Rule-based стратегия без внешних ключей.
- AI-генерация стратегии при наличии `OPENAI_API_KEY`.
- Экспорт бренд-отчёта в XLSX и PDF.

## Запуск

```bash
npm install
npm run dev:server
npm run dev
```

API работает на `http://localhost:8787`.

## Переменные окружения

```bash
PORT=8787
OPENAI_API_KEY=***
OPENAI_MODEL=gpt-4o-mini
```

Если AI-ключ не задан, сервис использует встроенную rule-based стратегию.

## Почему без базы и оплаты

Для первого понятного MVP важнее быстро проверить ценность: загрузил один или несколько отчётов → получил анализ → скачал стратегию. База, личный кабинет и оплата добавляются позже, когда понятны сценарии пользователей.
