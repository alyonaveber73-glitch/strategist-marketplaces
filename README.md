# Стратег для маркетплейсов

MVP AI-платформы для продавцов маркетплейсов: загружаете выгрузку из кабинета, сервис считает ключевые метрики, сохраняет историю анализа и формирует стратегию роста продаж на месяц.

## Что уже есть

- Frontend: React + TypeScript + Vite.
- Backend: Express API.
- Серверная загрузка CSV, XLSX, XLS и ODS.
- Автоматическая агрегация строк по SKU из всех листов файла.
- Сохранение проектов и истории анализов в `server/data/projects.json`.
- Метрики:
  - продажи;
  - заказы;
  - ДДР;
  - маржа;
  - показы;
  - клики;
  - корзины;
  - конверсии показ→клик, клик→корзина, корзина→заказ.
- Rule-based стратегия без внешних ключей.
- AI-генерация стратегии при наличии `OPENAI_API_KEY`.
- Экспорт отчёта в XLSX и PDF.

## Идея продукта

**Стратег для маркетплейсов** — платформа, куда продавец загружает данные из личного кабинета Ozon/WB, а AI-агент анализирует продажи, рекламу, маржинальность, остатки и конверсии. На основе данных агент генерирует стратегию роста продаж на месяц с конкретными действиями.

## Запуск

Установить зависимости:

```bash
npm install
```

Запустить backend:

```bash
npm run dev:server
```

Запустить frontend во втором терминале:

```bash
npm run dev
```

По умолчанию API работает на `http://localhost:8787`.

## AI-стратегия

Скопируйте `.env.example` в `.env` и добавьте ключ:

```bash
OPENAI_API_KEY=...
OPENAI_MODEL=gpt-4o-mini
```

Если ключ не задан, сервис использует встроенную rule-based стратегию.

## Экспорт

После анализа доступны ссылки:

- `/api/export/:analysisId.xlsx`
- `/api/export/:analysisId.pdf`
