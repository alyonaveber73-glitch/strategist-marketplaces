# Стратег для маркетплейсов

MVP+ AI-платформы для продавцов маркетплейсов: загружаете выгрузки из кабинета, сервис нормализует отчёты, считает метрики, учитывает юнит-экономику, сохраняет историю и формирует стратегию роста продаж на месяц.

## Что уже есть

- Frontend: React + TypeScript + Vite.
- Backend: Express API.
- Авторизация продавца: регистрация, вход, JWT-сессия.
- Хранение проектов, истории и справочников в SQLite: `server/data/app.sqlite`.
- PostgreSQL migrations-ready режим через `DATABASE_URL`; SQLite остаётся fallback для локальной разработки.
- Серверная загрузка CSV, XLSX, XLS и ODS.
- Готовые пресеты под выгрузки Ozon/Wildberries.
- Нормализация типов отчётов:
  - продажи;
  - реклама;
  - остатки;
  - акции/промо.
- Справочник юнит-экономики по SKU:
  - себестоимость;
  - комиссия;
  - эквайринг;
  - логистика;
  - налог.
- Импорт справочника юнит-экономики из XLSX/CSV/ODS.
- Роли команды и приглашения сотрудников.
- Billing API под Stripe: безопасный demo-mode без ключа.
- Docker Compose конфиг для деплоя с PostgreSQL.
- Метрики:
  - продажи;
  - заказы;
  - ДДР;
  - маржа;
  - остатки;
  - расходы по юнит-экономике;
  - показы;
  - клики;
  - корзины;
  - конверсии показ→клик, клик→корзина, корзина→заказ.
- Rule-based стратегия без внешних ключей.
- AI-генерация стратегии при наличии `OPENAI_API_KEY`.
- Экспорт бренд-отчёта в XLSX и PDF.

## Идея продукта

**Стратег для маркетплейсов** — платформа, куда продавец загружает данные из личного кабинета Ozon/WB, а AI-агент анализирует продажи, рекламу, маржинальность, остатки, акции и конверсии. На основе данных агент генерирует стратегию роста продаж на месяц с конкретными действиями.

## Запуск

```bash
npm install
npm run dev:server
npm run dev
```

По умолчанию API работает на `http://localhost:8787`.

## Переменные окружения

Скопируйте `.env.example` в `.env`:

```bash
PORT=8787
JWT_SECRET=change…tion
DATABASE_URL=postgres://user:password@host:5432/db
OPENAI_API_KEY=***
OPENAI_MODEL=gpt-4o-mini
STRIPE_SECRET_KEY=sk_live_...
STRIPE_PRO_PRICE_ID=price_...
STRIPE_TEAM_PRICE_ID=price_...
```

Если AI-ключ не задан, сервис использует встроенную rule-based стратегию. Если Stripe-ключ не задан, billing работает в demo-mode и никого не списывает.
