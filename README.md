# Стратег для маркетплейсов

MVP AI-платформы для продавцов маркетплейсов: загружаете выгрузку из кабинета, сервис считает ключевые метрики и формирует стратегию роста продаж на месяц.

## Что уже есть в MVP

- Витрина продукта на React + TypeScript + Vite.
- Загрузка CSV-файла.
- Автоматическая агрегация строк по SKU.
- Метрики:
  - продажи;
  - заказы;
  - ДДР;
  - маржа;
  - показы;
  - клики;
  - корзины;
  - конверсии показ→клик, клик→корзина, корзина→заказ.
- ТОП товаров.
- Блок рисков.
- Рекомендации на месяц.

## Идея продукта

**Стратег для маркетплейсов** — платформа, куда продавец загружает данные из личного кабинета Ozon/WB, а AI-агент анализирует продажи, рекламу, маржинальность, остатки и конверсии. На основе данных агент генерирует стратегию роста продаж на месяц с конкретными действиями.

## Запуск

```bash
npm install
npm run dev
```
